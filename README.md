# todo-demo

一个最小的 Todo 网页应用（纯 HTML + 原生 JS，无构建），用来给 dsh-superagent 练手。

## 现状

- 添加待办
- 勾选完成 / 取消完成
- 删除待办
- 一键把全部待办标记为已完成
- 一键清除所有已完成项
- 底部并排显示「未完成 N 项」和「已完成 N 项」，随添加 / 勾选 / 删除 / 清除已完成实时更新
- 数据只存在浏览器本机 `localStorage`，刷新不丢，换设备不会同步

## 运行

整个应用零依赖，不需要 Node 或任何构建工具。直接双击 `index.html` 即可，也可以用任意静态服务器：

```sh
python -m http.server 8080
```
